# 论文阅读笔记 / Paper Notes

手机友好的独立中文阅读笔记，提供来源核对与单文件离线版。
Mobile-friendly independent reading notes in Chinese, with source references and self-contained offline HTML.

- 第一篇 / First paper: https://lindams0903.github.io/paper-notes/extreme-wind.html
- 许可说明 / Rights: [RIGHTS.md](RIGHTS.md)

## 阅读 / Reading

点开链接即可阅读，无需登录。点击“下载离线版”，保存 HTML 后使用支持本地 HTML 的浏览器打开。全部文字、样式、脚本和原文页图均内嵌；DOI、书架和分享链接需要联网。仅访问在线页面不保证离线缓存。

Open the site without signing in. Download the standalone HTML for offline reading in a browser that supports local HTML files. Text, styles, scripts and paper-page images are embedded. DOI, library and sharing links require a connection. Visiting the website does not guarantee offline caching.

## 范围 / Scope

中文笔记由 AI 辅助整理，不是论文译文，不代表原作者背书。事实、数值及结论应回到原文核对。首篇含未经裁切或标注的完整原文页图，仅转换文件格式；分面裁切图不随公开版分发。

The notes are AI-assisted independent commentary, not a translation or an author-endorsed version. Verify facts, values and conclusions against the original paper. The first article includes intact paper-page images converted only in file format; cropped figure panels are excluded from the public version.

## 维护 / Maintenance

本仓库只包含经过检查的公开内容。原始档案、私人批注和本地工作文件保存在本地资料库，不上传。页面路径发布后保持稳定；更正内容时同步更新日期、目录和来源说明。发布源为 `main` 分支根目录；`.nojekyll` 使 HTML 原样托管。

Only reviewed public content belongs here. Source archives, private notes and working files stay in the local library. Preserve published URLs and update dates, the catalog and source notes when correcting content. GitHub Pages serves the root of `main`; `.nojekyll` keeps the static HTML unchanged.

本仓库没有为全部内容授予统一的开源许可；论文及第三方材料依各自许可使用。
No blanket open-source license is granted over the entire collection; papers and third-party materials retain their own licenses.
